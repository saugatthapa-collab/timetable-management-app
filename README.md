# Timetable Management App

A simple Android timetable app built with Kotlin and Jetpack Compose.

## Features
- Weekly timetable overview
- Add, edit, and delete classes
- Day-by-day organization
- Time and room tracking
- Local data persistence with Room
- Material 3 UI

## Run it
1. Open the project in Android Studio.
2. Let Gradle sync.
3. Run the `app` configuration on an emulator or device.

## Project structure
- `app/src/main/java/com/example/timetable` – app code
- `app/src/main/res` – resources and theme
- `app/build.gradle.kts` – Android module configuration

## Notes
This project is a clean starting point and can be extended with reminders, notifications, calendar export, or a more advanced weekly timetable UI.
